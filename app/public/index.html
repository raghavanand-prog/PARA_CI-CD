About this demo

      
    
        
  • The user store is in-memory — registered users do not persist across serverless cold starts. Register, then log in within the same session to see a token, and use it for the profile fetch.
    • 
        
  • Nothing typed here is sent anywhere except this API — no analytics, no third-party requests.
    • 
        
  • This page and the API it calls are served from the same origin, so no CORS configuration is needed here (there is no browser frontend calling the AWS-deployed copy of the API).
    • 
        
  • The actual DevSecOps pipeline — GitHub → CodePipeline → CodeBuild → 5 security gates → ECR → ECS Fargate → ALB — is documented in the repository's README and docs/.
    • 
        
  • The rate-limit indicator above reflects the API's real express-rate-limit middleware (100 requests / 15 minutes per client), read directly from the response's RateLimit-* headers — it is not a UI-only simulation.
